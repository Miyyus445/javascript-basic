# Soal Bab 7: Perulangan (Looping)

## Tujuan

Setelah mengerjakan latihan ini, diharapkan kamu mampu:

- Menggunakan perulangan `for`.
- Menggunakan perulangan `while`.
- Menggunakan perulangan `do...while`.
- Menggunakan `break` dan `continue`.
- Menggunakan perulangan untuk mengolah data sederhana.

---

# Soal 1 - Perulangan Pertama

Gunakan perulangan `for` untuk menampilkan tulisan berikut sebanyak **5 kali**.

Output:

```
Halo JavaScript
Halo JavaScript
Halo JavaScript
Halo JavaScript
Halo JavaScript
```

# Bonus Challenge ⭐

Buat program sederhana yang mensimulasikan antrean pelanggan.

Diketahui:

```javascript
const pelanggan = [
  "Andi",
  "Budi",
  "Citra",
  "Dewi",
  "Eko",
];
```

Gunakan perulangan untuk menampilkan:

```
Memanggil pelanggan: Andi
Memanggil pelanggan: Budi
Memanggil pelanggan: Citra
Memanggil pelanggan: Dewi
Memanggil pelanggan: Eko

Semua pelanggan telah dilayani.
```

> **Petunjuk:** Gunakan perulangan `for` untuk membaca setiap data dalam array.
