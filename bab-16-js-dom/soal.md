# Tugas Bab 16: Sistem Dashboard Santri dengan DOM

## 🎯 Deskripsi

Buat sebuah halaman web sederhana berupa **Dashboard Santri** menggunakan HTML, CSS, dan JavaScript.

Pada tugas ini, JavaScript harus digunakan untuk memanipulasi halaman HTML menggunakan **DOM**. Data santri dan aktivitas tidak boleh ditulis satu per satu secara langsung ke HTML.

---

## 📋 Data Awal

Gunakan data berikut:

```javascript
const santri = {
  nama: "Budi Santoso",
  kelas: "XI RPL",
  status: "Aktif"
};

const aktivitas = [
  "Login ke aplikasi",
  "Membaca materi JavaScript",
  "Mengerjakan latihan",
  "Mengumpulkan tugas"
];
```
