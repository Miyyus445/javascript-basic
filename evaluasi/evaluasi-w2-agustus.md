# Project: CLI Event Manager

## 🎯 Deskripsi

Buatlah sebuah aplikasi **Event Manager berbasis CLI (Command Line Interface)** menggunakan JavaScript.

Aplikasi digunakan untuk membantu pengguna mencatat dan mengelola acara, seperti:

- Seminar
- Workshop
- Kajian
- Pelatihan
- Meeting

Contoh tampilan:

```text
==============================
       EVENT MANAGER
==============================

1. Tambah Event
2. Lihat Event
3. Cari Event
4. Hapus Event
5. Lihat Statistik
6. Keluar
