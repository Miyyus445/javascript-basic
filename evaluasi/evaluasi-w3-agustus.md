# Project: Sistem Reservasi Event

## 🎯 Deskripsi

Buat sebuah aplikasi **Reservasi Event berbasis Web** menggunakan:

- HTML
- CSS
- JavaScript

Aplikasi digunakan untuk mencatat peserta yang ingin mengikuti sebuah event.

User dapat mengisi nama, email, dan pilihan event. Setelah form dikirim, data peserta ditampilkan pada halaman **tanpa reload**.

Contoh tampilan:

```text
========================================
        EVENT REGISTRATION
========================================

Nama:
[ Budi Santoso ]

Email:
[ budi@email.com ]

Event:
[ JavaScript Workshop ▼ ]

[ Daftar Sekarang ] [ Reset ]

Jumlah Peserta: 2


========================================
        DAFTAR PESERTA
========================================

1. Budi Santoso
   budi@email.com
   Event: JavaScript Workshop
   Daftar: 21 Agustus 2026

2. Andi
   andi@email.com
   Event: Web Development
   Daftar: 21 Agustus 2026
